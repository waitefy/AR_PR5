# Практика 5: Three.js WebAR

Весь код находится в `index.html`: HTML, минимальное позиционирование панели
и JavaScript с отдельными классами `Lighting`, `Model`, `Controls`, `ARApp`.
Кнопки, цветовое поле и селектор используют стандартное оформление браузера.

Запуск из каталога практики:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://localhost:8000. Three.js r128 загружается с CDN.
Для AR на телефоне нужны HTTPS и поддержка immersive-ar, hit-test,
local-floor и DOM overlay.

Требования задания 5, стр. 7 методички:

- Поворот кнопками ±15°, выбор цвета и замена куба на пирамиду с квадратным основанием.
- MeshStandardMaterial с roughness/metalness и карта окружения через PMREMGenerator.
- Разделение ответственности между классами.
- HTML-панель в AR; beforexrselect предотвращает конфликт кнопок с размещением.
- Hit-test, зелёное кольцо и фиксация объекта по тапу, как в задании 4.

Карту окружения программа создаёт из простой студийной сцены.
Весь `index.html` можно вставить в отчёт одним листингом.
Проверка камеры и устойчивости привязки требует реального устройства с WebXR.
